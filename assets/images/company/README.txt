hero.webp  (place this ONE LEVEL UP, in assets/images/, not in this folder)
  - The single full-screen hero photograph, referenced as
    assets/images/hero.webp in index.html.
  - One excellent real project photo. Landscape, ~2200-2400px wide.
  - This is the only image on the page that should NOT be lazy-loaded.

who-we-are.webp  (in this folder: assets/images/company/)
  - Real Seven Points site/office photo used in the "Who We Are" tab
    of the About Us section, next to the stats.
  - Portrait or square crop works best (the layout reserves a tall
    image column). ~1400-1800px on the long edge.

team.webp  (optional, in this folder)
  - Only add this if you have a real Seven Points team photo.
  - If you don't, leave it out — the "Our Team" tab is built with
    typography only and does not require an image. Do not substitute
    a stock photo of unrelated people.

founder-01.webp  (optional, in this folder)
  - Only add if you want a real founder photo in the Founders tab.
  - The section works without one (text-only) if you leave this out.
