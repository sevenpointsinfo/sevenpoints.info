Four images, one per delivery stage. These swap in and out of the
sticky image panel in the "What We Do" section as the visitor
scrolls past each stage.

planning.webp
designing.webp
construction.webp
management.webp

Real Seven Points site/project photography for each stage if you
have it (e.g. a site survey photo for Planning, a drawing/model shot
for Designing, an active construction photo for Construction, a
handover/walkthrough photo for Management). If a stage has no real
photo yet, it's fine to reuse your strongest project photo across
more than one stage rather than add a stock image — see index.html,
the img src values are easy to point at whichever file you have.

Recommended size: ~1800-2200px on the long edge, consistent aspect
ratio across all four (the layout uses a fixed 4:5 portrait frame).
